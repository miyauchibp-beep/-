# 整備写真の仕分け（ホームページ使用済み / 未使用）

ホームページ（miyauchi-bp.com）に載せた写真と PC の整備写真を照合し、
**使用済み** と **未使用** のフォルダに分けます。

- ファイル名ではなく **写真の見た目** で照合するので、サイト側でファイル名が変わっていたり
  縮小されていても見つけられます（撮影日時が一致する場合も使用済みと判定）。
- 元の写真は **コピー** するだけなので、元フォルダは変わりません。
- サイトの写真約 6,400 枚分の解析データ（`site_hashes.json`）は同梱済みです。

## 準備（初回だけ）

1. （Windows のみ）Python をインストール：<https://www.python.org/downloads/>
   （インストール画面で「Add python.exe to PATH」にチェック）
2. この `photo_sort` フォルダを PC にダウンロード

## 使い方

- **Windows**：整備写真のフォルダを **`写真仕分け.bat` の上にドラッグ＆ドロップ** するだけです。
- **Linux**（Ubuntu など）：Python は最初から入っています。端末で次を実行します。

  ```
  cd ~/ダウンロード/photo_sort
  ./写真仕分け.sh ~/ピクチャ/整備写真
  ```
  初回だけ必要な部品（`python3-pil` `python3-numpy`）を自動で入れます。

結果は写真フォルダの隣に作られる `写真仕分け結果` フォルダに入ります。

```
写真仕分け結果/
├─ 使用済み/      ← ホームページに載っている写真
├─ 未使用/        ← まだ載せていない写真
└─ 仕分け一覧.csv  ← 1枚ずつの判定とサイト上のURL（Excelで開けます）
```

サブフォルダ（車ごとのフォルダなど）の構成はそのまま保たれます。

## うまく分かれないとき

- 同じ場面の連写が「使用済み」に入りすぎる → 厳しくする：
  `py photo_sort.py "写真フォルダ" --threshold 4`
- 載せたはずの写真が「未使用」に入る → ゆるくする：`--threshold 9`
- 新しい記事を書いた後 → サイトの一覧を取り直す：`--refresh`
- コピーではなく移動したい → `--move`
