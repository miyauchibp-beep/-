# 問い合わせフォーム 項目追加スクリプト

宮内自動車の問い合わせ Google フォーム 3 つに、「希望作業」「予算の目安」「症状」「確認事項」の質問を追加します。
概算（金額の幅）を先にお返しし、合意できた方だけ詳細見積もりに進めるための変更です。

- 金額・自動見積もりはフォームに表示しません（追加するのは質問だけです）
- 既存の質問は削除・変更しません（オイル交換フォームの説明文だけ追記します）
- 何回実行しても重複しません（同じタイトルの質問があればスキップします）

## 追加される内容

| フォーム | 位置 | 追加する質問（すべて必須） |
| --- | --- | --- |
| ① オイル交換 | 説明文 | 「で計算します」の直後に概算返信の案内を追記 |
| | 「問い合わせ内容」の直前 | ご希望の作業（チェックボックス）→ ご予算の目安（ラジオ）→ 気になる症状（ラジオ） |
| | 最後 | 確認事項（チェックボックス） |
| ② 整備修理 | 「問い合わせ内容」の直後 | 症状について（段落）→ ご予算の目安（ラジオ） |
| | 最後 | 確認事項（チェックボックス） |
| ③ 鈑金塗装 | 「問い合わせ内容」の直前 | 保険を使う予定（ラジオ）→ ご予算の目安（ラジオ） |
| | 最後 | 確認事項（チェックボックス） |

## 手順

### 1. スクリプトを用意する

1. <https://script.google.com/> を、フォームのオーナーの Google アカウントで開く
2. 「新しいプロジェクト」を作成（請求書スクリプトとは別のプロジェクトにしてください）
3. `forms/FormUpdate.gs` の中身を `コード.gs` に丸ごと貼り付けて保存
4. 予算の区切りを変えたい場合は、冒頭の `BUDGET_CHOICES_OIL` / `BUDGET_CHOICES_REPAIR_BODY` を書き換える

### 2. コピーで試す（本番フォームは変わりません）

1. 上部の関数選択で `testOnCopies` を選び「実行」
   - 初回は権限の確認が出ます。「詳細」→「（安全ではないページ）に移動」→「許可」
2. 実行ログに「【テスト】〜」フォームの編集 URL が 3 つ出るので、開いて確認する
   - 質問の位置・文言・必須設定
   - プレビュー（目のアイコン）で回答画面の見え方
3. 確認が終わったら、テスト用フォーム 3 つをドライブから削除する

### 3. 本番に反映する

- 3 つまとめて：`updateAllForms` を実行
- 1 つずつ：`updateOilForm` / `updateRepairForm` / `updateBodyForm` を実行

実行ログに「追加」「スキップ（追加済み）」が表示されます。

## うまくいかないとき

- **「問い合わせ内容」という質問が見つかりません** と出た場合
  `listAllFormItems` を実行すると、各フォームの質問一覧がログに出ます（何も変更しません）。
  タイトルが違っていたら、冒頭の `ANCHOR_TITLE` を合わせてください。このエラーが出たフォームは何も変更されていません。
- **説明文に「で計算します」が見つからない** と出た場合
  説明文は変更せずに質問だけ追加しています。説明文はフォーム上で手動で追記してください。

## 補足

- 追加後に予算の区切りや選択肢を変えたい場合は、フォーム上で直接編集してください
  （スクリプトを再実行しても、追加済みの質問は上書きしません）。
- 回答をスプレッドシートに連携している場合、追加した質問は右端の列に追加されます。過去の回答はそのままです。
- フォームがセクションに分かれている場合、「確認事項」は最後のセクションの末尾に入ります。
