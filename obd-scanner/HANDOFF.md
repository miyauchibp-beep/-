# 引き継ぎメモ: OBD 診断 × Claude（宮内自動車）

最終更新: 2026-10-17。claude.ai のチャットで作った元の HANDOFF.md（2026-10-09、10-13 追記）を、
2026-10-12 の Claude Code での作業結果で更新したもの。詳しい経緯は README.md、今後の構想は ROADMAP.md。

## 目的
- 車の OBD を PC で読み、故障コード・フリーズフレーム・ライブデータを Claude に渡して
  「原因候補（可能性順）・確認手順・修理方法」を出させる。
- 将来: 整備履歴の蓄積と参照、スナップオン診断機のデータの取り込み、段階ごと（キー ON → 始動 → 暖機 → 走行）の総合診断。

## 現状（2026-10-12 時点で動いているもの）
- このフォルダの `run_scan.bat` をダブルクリック → COM ポート（Enter で前回の番号）→ 接続 → 読み取り → Claude 診断 → `scan_logs` に保存。
- 接続は「前回つながった設定 → 自動判別 → CAN 11bit 500k → トヨタ K-line（宛先 13・9600bps）」の順に自動で試す。
- 実車で確認済み:
  - トヨタ bB QNC21（H28-2）: CAN（プロトコル 6）。故障コードなし。
  - トヨタ アレックス NZE121（H17-9, 152813km）: **トヨタ式 K-line（ATSP4 / ATSH8113F1 / ATIB96 / ATIIA13）**。
    一般的な設定（宛先 33・10400bps）では絶対に繋がらない。Car Scanner の「ログのエクスポート」で判明。
    PID 01 は 1 バイトしか返さない（MIL・DTC 数のみ、レディネスなし）。較正 ID 31205100。車台番号は返さない。
    **リア O2（B1S2）が装着されているのに 0.000V 固定** → 実車のリア O2 系統の点検が必要（未実施）。
  - ダイハツ ハイゼットトラック S500P（R1-11, 64,410km）: CAN。較正 ID 52M32F10B511200。
    P0200 でインジェクターとスパークプラグを交換済み。2026-10-17 時点で現在・保留コードなし、
    **消せない故障コード（永久 DTC）に P0420** が残り、触媒・O2 のレディネス未完了。暖機しての 2,500rpm 測定は未実施（次回）。
- 2026-10-17 から `run_scan.bat` は段階ごとに測る: キー ON で読む →「続けてエンジンをかけて測りますか？」→ 始動を自動検知 →
  アイドリング →（暖機を待つか Y/N）→（2,500rpm を測るか Y/N。運転席から音と色の回転ゲージで案内、Enter 不要）→ まとめて Claude 診断。
  音の案内は実車で成功（15 秒間 100% 範囲内）。音が小さいと言われたので矩形波にして大きくした（実車未確認）。
- 元の `Downloads\OBD\obd_ai_diag.py`（python-OBD 版）は使っていない。こちらのツールで置き換え済み。

## 環境
- PC: Windows 11、Python 3.14、`pip install pyserial anthropic` 済み。API キーは環境変数 `ANTHROPIC_API_KEY`（設定済み）。
- ツールの場所: `C:\Users\Owner\Downloads\OBD_TEST\OBD_TEST`（`obd-scanner/dist/OBD_TEST.zip` を展開したもの）。
- アダプタ: ELM327 v1.5 互換 Bluetooth「OBDII」（00:1D:A5:07:85:F7）。
  - **2026-10-12 時点は COM7 が発信**（COM6 は着信）。ペアリングし直すと変わる。
    確認は「その他の Bluetooth 設定」→「COM ポート」タブの OBDII「発信」。
  - **スマホ（Car Scanner）と繋ぐと、PC とのペアリングが使えなくなる**。
    症状: COM を開くと「セマフォがタイムアウトしました（121）」。
    直し方: スマホで登録解除 → Windows で OBDII 削除 → アダプタ OFF→ON → 再ペアリング → 発信の番号を確認。
  - 着信側のポートを開くと「アクセスが拒否されました（13）」。
  - K-line は 1 項目あたり約 0.55 秒と遅い。
- スマホ: Android、Car Scanner（接続プロファイル「Toyota OBD-II / EOBD」）。ログのエクスポートで通信内容が見られる。
- 安定化電源付き充電器 WASINC100SOJ あり。
- 検討中のアダプタ: OBDLink MX+ / EX（購入前に価格・正規品かを確認）。

## スナップオン診断機（MTG-DUAL-TAB2-PRO）
- **Bluetooth（NANO-BT2、COM4/COM5）には触れない**。OBD 車検に関わる回線なので、ポートを開く・コマンドを送る・
  通信を横取りする、はすべてしない。ツールも COM4/COM5 は指定しても拒否する。
- 方針（2026-10-13 追記）: **USB 有線接続でファイルをコピーして取り込む**。
  1. 更新ソフトが動いていない時に、タブレットを USB で PC につなぐ（必要ならタブレット側で「ファイル転送」を許可）
  2. エクスプローラーで、診断結果・レポート・PDF・CSV・スクリーンショットが入っていそうなフォルダを探す
  3. **移動ではなくコピー**で、PC の作業フォルダ（例: `snapon_import`）に取り出す。
     タブレット内のファイルは削除・移動・名前変更をしない。アプリや更新に関わるフォルダには触らない
  4. 取り出した PDF・画像・CSV を、OBD のスキャン結果と一緒に Claude に渡す（読み込み部分は形式がわかってから作る）
- まだ分かっていないこと: PC にどう見えるか（ドライブか MTP か）、どこに何が保存されるか、
  診断データそのものがファイルとして残るか。**ユーザーが、つないだ時の画面を教えてくれる予定**。
- 並行案: スナップオン・ツールズへの問い合わせ、タブレットの「印刷」「PDF 出力」「メール」「共有」機能の確認。
- 取り込んだファイルにお客様の名前などが含まれる場合は、Claude に渡す前に確認する。

## 注意事項
- 車に送るのは読み取りだけ（モード 01/02/03/07/09/0A、接続テストでは 1A/21 も）。故障コードの消去・書き込みはしない。
- 実車での作業は、換気・キー操作・バッテリー電源の接続に注意する。
- Claude の診断は「候補」。断定せず、確認手順の順に実車で確かめる。
- 価格・在庫など購入に関する情報は、チャット時点のもの。
