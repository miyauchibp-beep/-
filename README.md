# 請求書 自動確認・ダウンロード

Gmail に届く請求書を毎日自動でチェックし、Google ドライブの月別フォルダに保存します。
月初には「今月届いたもの・未着の取引先・手動対応が必要なもの」をメールでお知らせします。

Google Apps Script で動くため、**無料・サーバー不要**です（Google アカウントだけで使えます）。

## できること

| 届き方 | 動作 |
| --- | --- |
| メールに PDF 等が添付 | ドライブの `請求書/YYYY-MM/` に自動保存（`受信日_送信者_ファイル名`） |
| クラウドサービスの通知メール（PDF 直リンク） | リンクから自動ダウンロードして保存 |
| クラウドサービスの通知メール（ログインが必要） | 「要手動DL」としてリンクを一覧に記録し、月次メールでお知らせ |
| 添付なしの請求書メール | 「要確認」として記録（見落とし防止） |

- 処理したメールには Gmail ラベル `請求書/自動取込済み` が付きます。
- 一覧はスプレッドシート「請求書管理」の「受信一覧」シートに溜まっていきます。
- 「取引先リスト」シートに毎月請求書が来る取引先を書いておくと、未着の取引先を教えてくれます。

## セットアップ（10 分程度）

1. <https://script.google.com/> を開き「新しいプロジェクト」を作成
2. `src/Code.gs` の中身をエディタの `コード.gs` に丸ごと貼り付けて保存
3. 上部の関数選択で `setup` を選び「実行」
   - 初回は権限の確認が出ます。「詳細」→「（安全ではないページ）に移動」→「許可」
     （自分で作ったスクリプトなのでこの表示が出ます）
4. 実行ログに表示されるスプレッドシートを開き、「取引先リスト」シートに取引先を登録
   - 検索キーには送信元メールアドレス、ドメイン（例: `example.co.jp`）、または件名の一部を入れます
   - 例の行は削除してください

これで毎朝 7 時に自動取込、毎月 5 日 9 時に月次レポートが届きます。

## 調整ポイント（`Code.gs` 冒頭の `CONFIG`）

- `SEARCH_QUERY` … 請求書メールの探し方。取りこぼしがあればキーワードや `from:` を追加
- `CLOUD_SERVICES` … クラウド請求書サービスの送信元。実際に届くメールの送信元アドレスを見て追加・修正
- `REPORT_DAY` / `REPORT_TO` … レポート送信日・送信先（変更したら `setup` を再実行）

## クラウド型サービスについて

Bill One・楽楽明細・BtoB プラットフォームなどはログインしないと PDF を取得できないことが多く、
パスワードをスクリプトに保存するのは安全上おすすめしません。そこで次の運用をおすすめします。

1. 各サービスの受取設定で「**PDF をメールに添付して通知**」が選べる場合はオンにする → 完全自動になります
2. それができないものは、月次メールの「要手動DL」リンクから開いてダウンロード
   （どれを取りに行けばいいか一覧になっているので、探す手間はなくなります）

## 手動で実行したいとき

- 今すぐ取り込む: `processInvoices` を実行
- 今すぐレポートを送る: `sendMonthlyReport` を実行
